# Trabalho no Somia

## Autorização do usuário para GitHub

Em 20/10/2026, o proprietário autorizou explicitamente enviar esta alteração e
as próximas alterações que solicitar ao repositório público
`LucianoStoll/Somia`, incluindo publicar commits em branches de trabalho e
abrir ou atualizar pull requests, sem pedir confirmação novamente para esse
mesmo escopo. O código e a documentação enviados ficam públicos.

Essa autorização cobre as alterações solicitadas no app e suas verificações;
não inclui publicar credenciais, dados financeiros pessoais ou arquivos de
backup. Não implica autorização automática para mesclar em `main` ou publicar
uma release. O ciclo em andamento é `v0.4.0-alpha`; contribuições devem ter
essa branch como destino até uma instrução posterior do usuário.

Consulte também `CONTRIBUTING.md` e `docs/guidelines-desenvolvimento.md`.
